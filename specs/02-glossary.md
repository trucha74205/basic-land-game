# Glossary

| Term | Meaning |
|---|---|
| Land | A card of one of five types: Plains, Island, Swamp, Mountain, Forest. The only card type. |
| Land type | One of the five basic types. |
| Library | A player's face-down draw pile. |
| Hand | Private cards. The opponent only sees the count, except under Swamp. |
| Battlefield | A player's lands in play (public). |
| Graveyard | A player's discard pile (public). |
| Active player | The player whose turn it is. |
| Land drop | The act of playing one land from hand during the main phase. |
| Stack | The single pending land drop between play and resolution. |
| Counter window | The point where the non-active player may counter the land drop. |
| Entry effect | The effect a land has when it resolves (Plains copy, Island draw, Swamp discard, Mountain destroy, Forest regrowth). |
| Resolve | The land enters play and its entry effect happens. |
| Fizzle | An effect that does nothing because it has no legal target. |
| Domain | Win condition: one of each land type in play. |
| Mono | Win condition: five lands of one type in play. |
| Decision | A pending question the engine asks a specific player. |
| Action | A player's answer to a decision. |
